# 01 — Bigrama

Primeiro notebook da trilha. Aqui construímos do zero um modelo de linguagem baseado em bigramas, usando apenas Python puro e um dataset minúsculo.

O objetivo não é criar um modelo poderoso, mas entender os princípios que estão na base de todo modelo de linguagem moderno, incluindo os LLMs.

---

## O que você vai aprender

- O que é um token e um vocabulário
- Como converter texto em números (tokenização)
- O que são bigramas e probabilidades condicionais
- Como um modelo gera texto de forma autoregressiva
- Por que contexto limitado é um problema fundamental

---

## Pré-requisitos

- Python básico (listas, dicionários, loops)
- `matplotlib` para visualização da matriz de bigramas (única dependência externa)

---

## Como executar

```bash
cd notebooks/01_bigrama
jupyter notebook notebook.ipynb
```
